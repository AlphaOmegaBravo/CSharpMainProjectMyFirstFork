Пышка: пекарня-мёрдж — загрузка в VK Mini Apps
================================================

ID приложения: 54817226 (уже прописан в vk-hosting-config.json)

Что внутри:
  build/index.html        — вся игра (один файл)
  vk-hosting-config.json  — настройки хостинга VK (app_id, папка build)
  package.json            — зависимость @vkontakte/vk-miniapps-deploy
  deploy.bat              — запуск загрузки в один клик (Windows)

Как загрузить:
  1. Установите Node.js (версию LTS) с https://nodejs.org, если его ещё нет.
  2. Распакуйте архив в любую папку и дважды кликните deploy.bat.
  3. При первом запуске скрипт сам установит инструмент VK (npm install).
  4. Появится ссылка — откройте её в браузере, войдите в VK под аккаунтом
     администратора приложения и разрешите доступ. Вернитесь в окно и нажмите Enter.
  5. Если VK пришлёт код подтверждения в сообщения — введите его в окне.
  6. Инструмент загрузит игру и выведет ссылки. По умолчанию версия выкладывается
     и в тестовую (dev), и в рабочую (production) среду.

Обновление игры: замените build/index.html новой версией и снова запустите deploy.bat.

На macOS / Linux вместо deploy.bat:  npm install  &&  npx vk-miniapps-deploy
Только тестовая среда:  set MINI_APPS_ENVIRONMENT=dev  перед запуском (Windows).
